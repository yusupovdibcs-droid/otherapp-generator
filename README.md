# Картинка otherapp

Страница собирает картинку для лендингов установки приложения `/app/<имя>`:
скриншот экрана установки из TestFlight вставляется в шаблон с двумя телефонами,
на выходе ZIP для разработки и готовый текст задачи.

Открыть: https://yusupovdibcs-droid.github.io/otherapp-generator/

## Как пользоваться

1. Загрузите вертикальный скриншот iPhone целиком.
2. Проверьте превью.
3. Укажите кодовое имя новой страницы латиницей и скачайте ZIP.
4. Вставьте адрес прошлого лендинга и ссылку TestFlight, скопируйте текст задачи.

## Что в архиве

```
<имя>-otherapp.zip
├── Source/    <имя>.png (562×508), <имя>@2x.png (1124×1016), без сжатия
└── Optimize/  <имя>.webp, <имя>@2x.webp, <имя>.png, <имя>@2x.png
```

Лимит веса: 1x до 150 КБ, 2x до 300 КБ. Если файл тяжелее, скачивание закрыто.

## Как это работает

- Вся обработка идёт в браузере, файлы никуда не отправляются. Страница работает без интернета: всё встроено в `index.html`.
- Скриншот вписывается в экран левого телефона по правилу Fill (по большей стороне, по центру).
- WebP кодирует сам браузер (Chrome, Edge, Firefox). Safari WebP не сохраняет, страница об этом предупредит.
- PNG сжимается квантованием до 256 цветов.

Библиотеки внутри: [pako](https://github.com/nodeca/pako) 1.0.11 (MIT), [UPNG.js](https://github.com/photopea/UPNG.js) 2.1.0 (MIT), [JSZip](https://github.com/Stuk/jszip) 3.10.1 (MIT).
